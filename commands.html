Commands

At a terminal you play The Halls of ZK by typing commands in plain English at the prompt. Over the telephone the same game is played with your phone's keypad.

At the Terminal

Commands can be strung together with full stops or THEN, and several objects can be named at once with AND. THE is optional. 

GET SACK AND LAMP
E. N. LOOK
command THEN command THEN command
TAKE object FROM object
Moving Around
N S E W

Or NORTH EAST, SOUTH WEST and so on
U D
Up and down

The Game
LOOK
Describe where you are
INVENTORY
List what you are carrying
SCORE
Your score so far
BRIEF VERBOSE
Short or full room descriptions; QUIET is the same as BRIEF
SAVE RESTORE
Save your game, or pick up a saved one
RESTART
Start again from the beginning
QUIT
Leave the game; Ctrl/Z does the same
VERSION
Which version of ZK this is
Doing Things

Most commands act on an object: something in the room, something you carry, or someone you meet. Words separated by a slash mean the same thing.

  • GET/TAKE/REMOVE object
  • DROP object
  • EXAMINE object
  • READ object
  • INVENTORY object
  • LOCATE object, WHERE IS object
  • LOOK AT object
  • LOOK IN object
  • PICK UP object
  • PUT DOWN object
  • WEAR object
  • PUT ON object
  • OPEN object [WITH object]
  • CLOSE/SHUT object [WITH object]

  • UNLOCK object [WITH object]
  • LIGHT/START object [WITH object]
  • STOP object [WITH object]
  • TURN ON/OFF object
  • SHUT OFF object
  • PUSH/PULL/MOVE object [direction]
  • PUT/MOUNT object IN/ON object
  • GIVE object TO object
  • BOOT object
  • INSTALL object

  • GET ON/OFF object

  • PLAY WITH object
  • RUB/FONDLE object [WITH object]
  • CURE/HEAL/REPAIR/FIX object [WITH object]
  • DESTROY/BREAK/KILL/SMASH/MUNG object [WITH object]
Talking and Typing
SAY words
Say something out loud
TELL someone, command
Ask someone to do something; ASK works too
TYPE digits
Type a number
LOOK UP "text"
Look up a word or name
HELLO
Be friendly
And the Rest

JUMP, SCREAM, WAIT and PRAY are all understood, as are a couple of magic words that adventurers of a certain age will remember.

On the Telephone

Over the phone there is nothing to type. The game reads each room aloud and you answer with your phone's keypad.
