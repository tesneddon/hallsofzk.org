Play

There are a number of ways to play The Halls of ZK, depending on whether you want to install the game on your own system or access it online (even through a browser or over the phone).

Play Online

The Halls of ZK can be played online in a web browser by navigating here. Login as user ZK at the prompt.

Web browser access is provided using DCL in a box served by WASD VMS Web Services from Mark Daniel, running on an OpenVMS VAX V7.3 system called BENDER:: .

Alternatively, BENDER:: is connected to HECnet , a world wide hobbyist DECnet Phase IV network. If your node database is not up to date, then use the DECnet address 12.2 and log in as user ZK. You can look the node details up here .

Play by Phone

The Halls of ZK can be played over the telephone by calling +61 8 6186 3484. The game is read aloud by DECtalk and you play using your phone's keypad.

When asked for your passcode, new players press # and then 1 to start a new game (or 2 to hear about the game first). You will be given a six digit passcode, read out twice. Keep it safe: it is how you get back to your saved game next time you call. The keypad and menu are described on the Commands page.

The game itself runs on OpenVMS VAX, just as it always has. The calls are answered by Asterisk, running on a small Linux box, which connects each caller to the VAX using FastAGI. The VAX sends the game's text and the Linux box turns it into speech with DECtalk and plays it down the line, then passes the caller's key presses back to the game.

Play Locally

Alternatively, if you would rather install ZK on your local VAX, Alpha, I64 or x86-64 OpenVMS system, the individual software packages can be downloaded below:

ZK011-A.ZIP
VMSINSTAL kit
ZK011-B.ZIP
OpenVMS VAX images
ZK011-C.ZIP
OpenVMS Alpha images
ZK011-D.ZIP
OpenVMS I64 images
ZK011-E.ZIP
OpenVMS x86-64 images

Alternatively, all parts of the kit are available in a single zip file, ZK013.ZIP.

The complete source code can be downloaded from the GitHub project page.

Although ZK is shipped as a VMSINSTAL kit, it can be extracted from the relevant, architecture specific saveset and run without installing system-wide. To do this, execute the following commands: 

$ VERSION = "011"
$ ARCH_TYPE = F$GETSYI("ARCH_TYPE")
$ ARCH_EXTN = F$ELEMENT(ARCH_TYPE,",",",B,C,D") - ","
$ COPY/FTP/ANONYMOUS/VERBOSE/LOG -
    ftp.endlesssoftware.com.au::"/pub/zk/kits/zk''VERSION'.''ARCH_EXTN'" -
    SYS$DISK:[]
$ BACKUP ZK'VERSION'.'ARCH_EXTN'/SAVE_SET []
$ RUN ZK$MAIN.EXE

Reporting Problems

Found a bug in the game, a problem with the phone or online versions, or a mistake on this website? Please check the ZK issues page on GitHub to see whether it has already been reported, and if not, open a new issue. It helps to say which version you were playing (terminal, online or phone), where you were in the game and what you did just before it went wrong.
